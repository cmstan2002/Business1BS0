## How to use these
- Each PDF leads with a cover page showing topic, total questions, and series breakdown
- Questions are **grouped by sub-topic** (e.g. 1.3.2 Revenues, 1.3.3 Cash-flow, 1.3.4 Sources of finance)
- Within each sub-topic, questions appear in chronological order (Specimen → June 2024)
- Each question shows: series · paper · question number · section · command word · marks
- Case-study context appears in a yellow callout above questions that need it
- The mark scheme answer appears below each question in a green expandable section (always open in PDF)

## Why some Paper 2 questions appear in Paper 1 topic banks
The Edexcel spec only lists sub-topics like "Sources of finance" (1.3.4) under Theme 1, even though Paper 2 also tests them. Questions about retained profit, share capital, etc. on Paper 2 are therefore filed under 1.3.4 — search the *series* metadata in each entry to filter by paper.
