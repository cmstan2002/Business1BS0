## 🚀 How to open in Obsidian

1. **Open Obsidian** → **Open folder as vault** → select `/Users/chris/Business1BS0/`
2. **Settings → Community plugins → Browse → install "Spaced Repetition"** (turn it on; it auto-detects the `?` flashcard format)
3. **Settings → Community plugins → Browse → install "Dataview"** (optional — helps the Dashboard checklists)
4. **Settings → Files & Links → Default location for new notes → "Specified folder" →** `Topics/Paper 1` (so new notes don't clutter root)
5. **Settings → Appearance → Theme → "Things"** or any clean theme works
6. **Open `Dashboard.md`** and pin it. From there everything is wiki-linked.
